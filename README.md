# Contact Management System

Full-stack contact manager built for the 10Pearls Shine program (Java + React).

## Tech Stack
- Backend: Java 21, Spring Boot, Spring Data JPA, Spring Security (JWT)
- Database: SQL Server
- Frontend: React.js
- Testing and quality: JUnit, Mockito, SonarQube

## Project Structure
- `backend/` Spring Boot API
- `frontend/` React app
